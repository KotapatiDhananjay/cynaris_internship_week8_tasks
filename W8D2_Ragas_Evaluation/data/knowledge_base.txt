Artificial Intelligence (AI) is the ability of machines to perform tasks that normally require human intelligence. These tasks include problem solving, learning, reasoning and decision making.

Machine Learning (ML) is a branch of Artificial Intelligence. It enables computers to learn patterns from data and make predictions without being explicitly programmed for every task.

Deep Learning is a subset of Machine Learning. It uses artificial neural networks with multiple layers to learn complex patterns from large datasets.

Natural Language Processing (NLP) is a field of AI that enables computers to understand, process and generate human language. NLP is used in chatbots, translation and text classification.

A Large Language Model (LLM) is an AI model trained on large amounts of text. It can understand and generate human language and answer questions.

Retrieval Augmented Generation (RAG) combines information retrieval with language generation. It retrieves relevant information from external documents and uses that information to generate grounded answers.

A vector database stores numerical vector embeddings and supports similarity searches. It helps applications retrieve semantically similar information.

ChromaDB is an open-source vector database. It stores embeddings and performs similarity searches. It is commonly used in Retrieval Augmented Generation applications.

LangChain is a framework used to develop applications powered by language models. It supports document loading, text splitting, retrieval and language model integration.

Ragas is a framework used to evaluate Retrieval Augmented Generation systems. It provides metrics such as faithfulness, answer relevancy, context precision and context recall.

Faithfulness measures whether an answer is supported by the retrieved context. Answer relevancy measures whether the generated answer addresses the user's question. Context precision measures whether relevant retrieved information is ranked above irrelevant information. Context recall measures whether the retrieved context contains the information needed to answer the question.

Chunk size determines how large each document section is during text splitting. Retrieval k determines how many relevant document chunks are returned by the retriever. Adjusting chunk size and retrieval k can improve RAG performance.
